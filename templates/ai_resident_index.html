Configure Discord Credentials

To customize servers, you must configure your Discord Developer Client Credentials. This handles user authorization and loads settings securely.

Steps to Setup:

  1. Go to the Discord Developer Portal.
  2. Open your Discord Application client.
  3. Copy the Client ID and Client Secret (found under OAuth2).
  4. Go to the Global Keys Editor page (God Mode only) and input them.
  5. Set Redirect URI to: http://your-ip:port/ai_resident/oauth/callback (or localhost).
